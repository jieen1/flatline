# ADR-4: 预期来自资产自身历史

- 状态：accepted
- 日期：2026-08-20
- 决策者：Flatline 设计（系统设计 v0.4 §2、§3.1）

## 背景

识别"静默失效"需要预期：资产"该出现却没出现"。预期的来源有几种可能——跨用户群体基线、候选集观测（资产本可被调用的全集）、或资产自身的历史参与。个人用户数据量有限，且候选集不可观测（系统设计 v0.4 §0、§2 原则 1）。

## 决策

每个资产的预期（基线）来自它自身的历史参与：滚动窗口内该资产在机会 Session 中的参与率与绝对次数。不依赖候选集观测，不做跨用户比较；基线在资产详情中可见、可解释、可下钻（分子/分母/窗口）。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 自身历史基线（本决策） | 个人数据量足够；可解释、可下钻；无隐私暴露 | 新资产无基线（由 dormant/no_opportunity 状态如实表达） | 采纳 |
| 匿名群体参考区间 | 冷启动有参照 | 需上传聚合数据，违背 ADR-1 隐私边界 | 拒绝，进入 Backlog |
| 候选集观测（"本可被调用"全集） | 理论上更准 | 候选集不可观测，无法实现 | 拒绝 |

## 后果

- 正面：判定完全基于本地可验证数据，符合证据纪律（无证据不判定）；基线可下钻满足"每个比例可见分子分母"（roadmap 验收标准 6）。
- 负面：历史不足的资产长期处于 dormant/no_opportunity，需 UI 如实展示而非伪装健康。
- 对 MVP 边界：群体参考不进入 MVP（AGENTS.md §6）。
