# ADR-1: 本地优先

- 状态：accepted
- 日期：2026-08-20
- 决策者：Flatline 设计（系统设计 v0.4，沿用 v0.3）

## 背景

Flatline 追踪的是用户本地 Agent 资产（Skill、AGENTS.md、Rule、Hook）在真实工作会话中的参与情况，数据源是本地 Session 历史与本地资产文件。个人用户的数据量与隐私敏感度决定了产品不能依赖云端（系统设计 v0.4 §1.4、§6；AGENTS.md §7）。

## 决策

Flatline 是本地优先产品：不默认上传任何本地数据，全流程不依赖登录；只监听 loopback 地址（127.0.0.1）；不引入遥测、不引入第三方网络请求。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 本地优先（本决策） | 无隐私暴露面；无网络依赖；个人数据量足够支撑核心功能 | 无跨设备/跨用户能力 | 采纳 |
| 可选云同步 | 多设备可用 | 引入账户、上传、隐私边界例外，超出 MVP 边界（AGENTS.md §6） | 拒绝，进入 Backlog |
| 匿名群体参考 | 提供群体基线 | 需要上传聚合数据，违背本地优先与隐私边界 | 拒绝，进入 Backlog |

## 后果

- 正面：隐私边界成为硬约束（DEVELOPMENT.md §8 开发红线）；无网络依赖使构建与验收更简单（roadmap P1 验收标准）。
- 负面：无账户/同步/团队协作能力；任何未来引入网络依赖的提案必须先落 ADR 并说明隐私边界例外。
- 对 MVP 边界：账户/云同步/团队、群体参考明确不进入 MVP（AGENTS.md §6）。
